## Cómo ejecutarlo en IntelliJ IDEA

1. Abre IntelliJ IDEA y elige **Open**.
2. Selecciona la carpeta raíz del repositorio (`Hackaton Java`).
3. Marca `src` como **Sources Root** (clic derecho en `src` → Mark Directory as → Sources Root), si no quedó así.
4. Configura el JDK del proyecto (File → Project Structure → Project SDK). Sirve JDK 17 o 21.
5. Abre `src/clinica/Main.java` y pulsa **Run**.
6. El working directory debe ser la **raíz del proyecto**. Los CSV se crean en `datos/` al salir (opción 0).
